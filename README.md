## 🚀 GitHub Pages-এ লাইভ করার নিয়ম (Deployment Guide)

১. এই রিপোজিটরির **Settings** ➔ **Pages** ট্যাবে যান।  
২. **Build and deployment** সেকশনে:  
   - **Source:** `Deploy from a branch`  
   - **Branch:** `main`  
   - **Folder:** `/ (root)`  
৩. **Save** বাটনে ক্লিক করুন। ১ মিনিটের মধ্যে সাইট লাইভ হয়ে যাবে!  
৪. কাস্টম ডোমেইন থাকলে `Custom domain` বক্সে `www.purenestbd.shop` লিখে দিন।
